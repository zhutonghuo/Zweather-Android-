# Zweather-Android-
🌤️ Zweather · 天气应用

一款零第三方依赖的纯原生安卓天气 App（包名 com.zhutonghuo.weather），数据源明确标注 uapis.cn（免 Key 直连）。

核心能力：

📍 自动定位：取经纬度 → 逆地理成城市名 → 自动拉天气。
⌨️ 自定义输入：顶部搜索框直接查任意城市。
🗺️ 地图选点：自绘高德公开瓦片地图（免 SDK/Key），拖动平移、双指缩放、中心准星取坐标 → 反查城市。
🧩 4×2 卡片：第一行「今天」、第二行「明天」，每行 4 格（白天/夜间/最高/最低）。
⏰ 附 24 小时逐时条 + 未来 7 天列表。
✨ 18 项生活指数：穿衣、紫外线、洗车、运动、花粉等，点卡片看建议。
🎨 整页随天气变主题渐变、卡片立体阴影 + 水波纹、区块淡入动效；常显「数据来源：uapis.cn」。
